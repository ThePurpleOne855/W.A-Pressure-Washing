# W.A Pressure Washing

Static marketing site for W.A Pressure Washing (Kissimmee, FL).

## Run locally

```bash
npm run dev
```

Then open http://localhost:3000

## Site files

The live site lives in the [`PowerWash/`](PowerWash/) folder (`index.html`, `components.jsx`, `pages.jsx`, `styles.css`, and `assets/`).

## GitHub Pages

Pushes to `Main` deploy automatically via [`.github/workflows/deploy-pages.yml`](.github/workflows/deploy-pages.yml).

**One-time setup:** In the repo on GitHub, go to **Settings → Pages** and set **Build and deployment → Source** to **GitHub Actions**.

After the first workflow run, the site will be at:

`https://thepurpleone855.github.io/W.A-Pressure-Washing/`
